# 🏦 Bank Management System

A simple Bank Management System built using Java, OOP, HTML, CSS, and JavaScript.

## 🚀 Features

- Account details
- PIN verification
- Deposit and withdraw money
- Balance checking
- Transaction history
- Input validation
- LocalStorage data saving
- Responsive frontend design

## 🛠️ Technologies Used

- Java
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 🌐 Live Demo

[View Live Demo](https://soni-frontend.github.io/Bank-Management-System/)

## 📌 About

This project includes a Java console-based Bank Management System and an interactive frontend demo.

The frontend currently works independently using JavaScript and LocalStorage.
